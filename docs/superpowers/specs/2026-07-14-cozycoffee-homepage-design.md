# CozyCoffee 首页重设计规格

**日期**: 2026-07-14
**状态**: 已冻结，待实现
**设计方向**: 余白の温度 (Warm Reserve) — 日式克制 + 咖啡的温度感

---

## 1. 设计目标

将首页从模板化的信息陈列页，转变为**品牌叙事 + 会员转化**驱动的体验。用户打开官网 → 被咖啡品质打动 → 理解积分生态的价值 → 产生注册冲动。

核心差异化：**独特的会员积分生态**。

---

## 2. 设计系统

### 2.1 色彩

策略：整体 Restrained（纯白底），会员叙事区形成唯一的 Committed Moment（深色背景）。

```css
:root {
  --bg: oklch(1 0 0);                      /* 纯白 */
  --surface: oklch(0.97 0.003 42);          /* 极微暖灰，卡片/分区 */
  --primary: oklch(0.42 0.09 42);           /* #753A22 深烘咖啡棕 */
  --primary-hover: oklch(0.35 0.08 42);     /* 悬停态 */
  --on-primary: oklch(0.98 0 0);            /* 主色上文字 */
  --accent: oklch(0.50 0.07 135);           /* #526C43 釉面绿 */
  --accent-soft: oklch(0.92 0.03 135);      /* 绿色浅底色 */
  --on-accent: oklch(0.98 0 0);
  --ink: oklch(0.17 0.008 42);              /* 正文墨黑 */
  --muted: oklch(0.46 0.008 42);            /* 辅助文字 */
  --surface-alt: oklch(0.25 0.025 42);      /* #2C1E18 深色叙事区 */
  --border: oklch(0.89 0.004 42);           /* 分割线 */
}
```

**使用规则**：
- primary 不零散撒在标题、图标、边框上——集中在按钮、链接和会员区
- accent（釉面绿）仅用于：积分到账数字、进度填充、已解锁/已升级状态标记
- surface 不连续覆盖多个整屏 section
- surface-alt 仅在 Membership 区和 Footer 使用

### 2.2 字体

统一无衬线系统，不加载外部字体。

```css
--font-sans: -apple-system, BlinkMacSystemFont, "Segoe UI",
  "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", Arial, sans-serif;
```

**排印规则**：
- Hero 标题: `clamp(2.75rem, 6vw, 5rem)`, 字重 600
- Section 标题: `clamp(2rem, 4vw, 3.25rem)`, 字重 600
- 正文: 16-18px, 行高 1.65-1.8
- 中文标题字距: 0 至 0.02em
- 正文宽度: 中文约 28-34 字/行，英文 ≤ 65-75ch
- 深色区浅色文字行高 +0.05-0.1

### 2.3 间距

基于 4px 网格: 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 / 128

### 2.4 形状与阴影

- 圆角: 图片 0-8px, 容器 8-12px, 卡片上限 16px
- 阴影: 默认无阴影，仅浮层和悬停使用轻微阴影
- 焦点态: 按钮和链接需可见的 keyboard focus ring

### 2.5 动效

- 入口淡入仅用 opacity（不用 translateY）
- `@media (prefers-reduced-motion: reduce)` 回退为即时显示
- Hero 如使用视频，需 poster + 暂停控制

## 3. 页面结构

### 3.1 导航栏（NavBar）

- 固定顶部，纯白半透明 `background: rgba(255,255,255,0.95)` + `backdrop-filter: blur(10px)`
- 进入深色 Membership 区时保证导航文字对比度
- 滚动至深色区后导航可转为不透明白底

### 3.2 Hero

**定位**: 产品优先，会员入口降级

- 静态咖啡萃取摄影（非轮播），占据约 70vh
- 标题: "把产地的风味，留在这一杯里"
- 副标题: "巴西·埃塞俄比亚·哥伦比亚 ｜ 小批次新鲜烘焙"
- 主 CTA: [查看菜单] — 实心 primary 按钮
- 次级链接: "会员如何回馈每一杯 →" — 文字链接，滚动至 Membership 区
- 摄影 overlay 从底部向上渐变至透明，保证白色文字对比度

### 3.3 豆源故事（Origins）

**定位**: 证明品质

- 非三等分卡片布局：一主横图 + 一窄竖图 + 一文字主导小块
- 移动端按 DOM 顺序自然折叠
- 转场语: "三处产地，成为今天杯中的六种表达。"
- 获奖信息嵌入豆源叙事中（如与豆源直接相关），品牌综合奖项放在 Menu 后

### 3.4 精品推荐（Menu）

**定位**: 制造欲望

- 3×2 响应式网格（`repeat(auto-fit, minmax(280px, 1fr))`）
- 价格始终可见（不隐藏在 hover 中）
- Hover: 显示风味描述或"加入购物车"动作
- 转场语: "选好这一杯，也开始记录下一杯。"

### 3.5 会员叙事（Membership）— Committed Moment

**定位**: 积分生态吸引 → 注册转化。深色背景 `surface-alt`。

**未登录状态**（首页默认）:

```
以白银会员为例

¥32 手冲咖啡
基础积分 32  +  等级加成 3
35 积分到账

当前积分 131 / 150
━━━━━━━━━━━━━━━━░░ 87%
距 5 元代金券还差 19 积分

白银会员 · 每杯 1.1×
每周五会员日额外 +0.5× · 生日 BOGO 券

[立即入会]    查看完整等级权益 →
```

**数据来源**: 基于后端真实规则
- 积分倍率: basic=1.0x, silver=1.1x, gold=1.2x, diamond=1.3x, black=1.5x
- 周五会员日额外 +0.5×
- 5元代金券 = 150 积分

**已登录状态**: 读取真实等级、积分余额、兑换目标、本月杯数

**微型等级速览表**（五行，非五列卡片）:

| 等级 | 门槛 | 倍率 | 代表权益 |
|------|------|------|----------|
| 基础 Classic | 0 EXP | 1.0× | 周三 1.5× 积分 |
| 白银 Silver | 500 EXP | 1.1× | 积分兑换 9.8 折 |
| 黄金 Gold | 1,500 EXP | 1.2× | BOGO + 8.8折券×2 |
| 钻石 Platinum | 4,000 EXP | 1.3× | 免单券 + BOGO×2 |
| 黑金 Black | 9,000 EXP | 1.5× | 免单券×2 + 无限免配送 |

**视觉规则**:
- 不使用悬浮卡片——交易、进度、权益直接排版在深色 section 内
- 釉面绿仅标记: 到账数字、进度填充、已解锁状态
- [立即入会] 使用实心 primary 按钮
- [查看完整等级权益 →] 使用白色文字链接
- 进度条使用 `<progress>` 或补充 `aria-valuenow/min/max`

### 3.6 页脚（Footer）

- 背景: `surface-alt` (与 Membership 同色)
- 通过间距 + 完整分隔线区分
- 保持现有三列布局: 联系方式 / 社交媒体 / 版权

## 4. 页面间过渡

- Origins → Menu: "三处产地，成为今天杯中的六种表达。"
- Menu → Membership: "选好这一杯，也开始记录下一杯。"

---

## 5. 状态覆盖

- 图片加载失败: 显示占位符
- 菜单数据不可用: 空状态提示
- 会员区未登录/已登录: 两种状态（见 3.5）
- 移动端: Origins 按 DOM 顺序折叠，Menu 1-2列，等级表横向滚动
- 减少动画: `prefers-reduced-motion` 回退

---

## 6. 绝对禁令

- ❌ 渐变文字（移除黑金卡现有渐变文字）
- ❌ 侧边条纹边框装饰
- ❌ Glassmorphism 默认使用
- ❌ 每个 section 上方小号全大写 eyebrow
- ❌ 卡片套卡片
- ❌ 奶油色/米色页面底色
- ❌ 价格仅在 hover 显示
- ❌ 五张等权彩色等级卡片

---

## 7. 实现范围

**改动的文件**:
- `src/assets/styles/style.css` — 全局色彩变量、Hero、Menu、Membership、Footer 样式
- `src/views/Home.vue` — 模板结构重构
- `src/assets/styles/nav.css` — 微调深色区导航适配
- `src/assets/styles/footer.css` — 背景色统一

**不改动的文件**:
- 登录/注册页面
- 会员中心内部页面
- 管理后台
- 移动端 (uni-app)
